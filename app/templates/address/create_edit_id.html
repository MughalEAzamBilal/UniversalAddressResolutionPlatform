Why an Edit ID is Required & How It Works

🔐
Public Link vs. Private Editing

Your address gets a 6-character Public ID (e.g. ab1226) that couriers and friends can view and copy. To protect your address from unauthorized edits or tampering, only you with your secret Edit ID can edit it.

🚫
Zero Passwords or Accounts

No username, password, or email is needed! Just select your parents' initials, your ID ending, and your birth date — easy to recall anytime without password resets.

🛡️
Cryptographically Private

Your Edit ID is salted and hashed with Argon2id encryption. It is never exposed in the public resolver link and cannot be seen by riders.

✨
Strictly Unique Per Person

Edit IDs can never be identical or same across users. If base initials and DOB ever coincide, an automatic sequence (e.g. -2) guarantees exclusivity.

The Edit ID Formula (13 Characters)
Public ID (6 chars) + Father's Initial (1) + Mother's Initial (1) + Last 3 digits of CNIC (3) + DOB Year YY (2) = ab1226MA12391

💡 Suggestion: How to fill your 13-Character Edit ID
Your 13-Character Edit ID is assembled following this exact sequence:
1. Public ID (6)
e.g. ab1226
2. Father Initial (1)
e.g. Muhammad → M
3. Mother Initial (1)
e.g. Ayesha → A
4. CNIC Last 3 (3)
e.g. ...123 → 123
5. DOB Year (2)
e.g. 1991 → 91
Result: ab1226MA12391 (6 + 1 + 1 + 3 + 2 = Exactly 13 characters, case-insensitive)
